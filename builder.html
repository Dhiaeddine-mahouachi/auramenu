Supported edits and CSV format

One command per line: Set price of "Cheeseburger" to 280, Rename product "Ayran" to "Fresh Ayran", Remove product "Ayran", or Set restaurant name to Istanbul Burger.

CSV header: category,name,price,description. Quote values containing commas. Prices must be explicit numbers.
